Claves NVM usadas para preferencias no-volátiles
Actualizado al 2026/10/02

Se lista en primer nivel el key del grupo para uso en Preferences.begin()
y en segundo nivel el key del item, su tipo de dato y su propósito.

El tipo bool se representa internamente como 1 byte, valores 1 o 0 para ACTIVO
o INACTIVO, respectivamente.

El tipo uint8_t[N] representa un blob binario de exactamente N bytes de longitud
que no corresponde a una cadena de texto ASCII, y en particular NO debe guardarse
ni interpretarse con \0 como byte de fin de cadena.

YUBOX/LoRaWAN
    devEUI          uint8_t[8]  Identificador de Device EUI de LoRaWAN. En la configuración inicial
                                este identificador debe guardarse para considerar que la configuración
                                es válida. Por omisión se guarda a un valor basado en la MAC del
                                dispositivo, rellenado con ceros al final.
    appEUI          uint8_t[8]  Identificador de Application EUI de LoRaWAN. Si la red LoRaWAN remota
                                no hace uso de este valor, se debe rellenar con ceros. Este valor debe
                                existir para que la configuración sea válida.
    appKey          uint8_t[16] Valor de Application Key que sirve de contraseña para negociación OTAA.
                                Este valor debe existir para que la configuración sea válida.
    region          uint8_t     Número que identifica a la región LoRaWAN. Si el valor no está definido,
                                o si no es válido, se asume región AU915 que corresponde al valor 0x01.
                                La numeración es la del enum LoRaMacRegion_t de SX126x-Arduino, que se
                                preserva con RadioLib:
                                    0 AS923     1 AU915     2 CN470     3 CN779 (*)  4 EU433
                                    5 EU868     6 KR920     7 IN865     8 US915      9 AS923_2
                                   10 AS923_3  11 AS923_4  12 RU864 (*)
                                (*) No soportadas por RadioLib. Si están guardadas, se reporta error y se
                                asume AU915 con subbanda 2.
    subband         uint8_t     Sub-banda inicial para establecer comunicación OTAA. El rango de subbandas
                                depende del soporte de subbandas de la región específica LoRaWAN. Por
                                omisión se asume subbanda 1. Con RadioLib, US915 y AU915 aceptan 1 a 8,
                                CN470 acepta 1 a 12, y las regiones de canales dinámicos sólo aceptan 1.
                                Un valor fuera de rango se reemplaza por 1.
    txduty          uint32_t    Intervalo (en segundos) entre transmisiones sucesivas de paquetes LoRaWAN.
                                Por omisión, y el valor mínimo posible, 10 segundos.
    txconfretries   uint32_t    Número de reintentos de transmisión confirmada. Este número de reintentos
                                se aplican encima de los reintentos internos de la biblioteca LoRaWAN.
                                Por omisión 3 reintentos. Sólo aplica para transmisiones confirmadas.

Las siguientes 3 claves están en el namespace YUBOX/LoRaWAN pero NO DEBEN ASIGNARSE externamente porque
sirven para mantener el estado de sesión LoRaWAN de RadioLib luego de negociar usando OTAA. En flasheo de
preparación estas variables deben NO EXISTIR.
    lwnonces        uint8_t[N]  (interno) Buffer de nonces de RadioLib (DevNonce y JoinNonce). Se conserva al
                                descartar la sesión, para que el DevNonce siga creciendo. Se borra junto con
                                las credenciales.
    lwsession       uint8_t[N]  (interno) Buffer de sesión de RadioLib. Se guarda luego de join, de cada
                                downlink, de cambio de clase, y cada 32 uplinks.
    lwfcntup        uint32_t    (interno) Siguiente contador de uplink. Se guarda luego de cada uplink para
                                no reescribir la sesión completa. Al restaurar se usa el mayor valor entre
                                éste y el de la sesión, más un margen de 2.

Las siguientes 5 claves eran usadas por la implementación anterior basada en SX126x-Arduino. Su contenido no
es compatible con RadioLib, y se borran automáticamente al arrancar si existen.
    NwkSKey         uint8_t[16] (obsoleto) Caché de Network Session Key.
    AppSKey         uint8_t[16] (obsoleto) Cache de Application Session Key.
    devaddr         uint32_t    (obsoleto) Caché de Device Address.
    uplinkcnt       uint32_t    (obsoleto) Caché de contador de paquetes uplink.
    downlinkcnt     uint32_t    (obsoleto) Caché de contador de paquetes downlink.
